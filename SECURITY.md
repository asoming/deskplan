# Security / 安全反馈

Please report security issues using the repository's **Security → Report a vulnerability** private reporting flow. Do not post exploit details, private tasks, local files, tokens or full backups in a public issue.

发现安全问题请使用仓库 **Security → Report a vulnerability** 私密报告入口，不要在公开 Issue 中提交利用细节、个人任务、本地文件、令牌或完整备份。

Include the affected version, operating system, minimal reproduction with sample data, and expected impact. Reports are reviewed on a best-effort basis; no response-time guarantee is offered. Fixes target the current release; older versions do not have a separate maintenance branch.

请提供受影响版本、系统、示例数据复现步骤与可能影响。当前按实际能力处理，不承诺响应时限；修复面向当前版本，旧版本没有独立维护分支。
