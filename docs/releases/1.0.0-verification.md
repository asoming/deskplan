## Signing and scope / 签名与范围

Windows is **not Authenticode signed**. macOS uses an **ad-hoc signature and is not notarized**. The macOS check verifies bundle integrity, not trusted publisher identity or Gatekeeper acceptance. First launch may be blocked or prompt for system review. No global security setting needs to be disabled by the app.

Windows 未配置发行者证书；macOS 未配置 Developer ID 与 Apple 公证。通过自动化验证不等于具有可信发行者签名。测试也不代表所有 Linux 桌面环境、系统通知服务与系统权限配置的表现都相同。

The UI is Simplified Chinese; README and product introductions are bilingual. Tasks are local and offline; there is no cloud sync or OS-calendar two-way sync. File attachments are path references, so task backups do not include the original file contents. Old schema 1/2 data is upgraded to schema 3; restore an older backup before rolling back to an older application version.
