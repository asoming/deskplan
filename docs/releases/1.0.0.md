# 日序 · Rixu 1.0.0

让计划留在桌面，让注意力留给今天。正式版提供 Windows、Linux、Apple Silicon 与 Intel Mac 安装包。

## 中文

- **今天 / 本周 / 四象限 / 收集箱**：三件今日重点、拖动排序、预计耗时与每日负荷。
- **四档紧急程度**：红色马上做、橙色尽快做、蓝色按计划做、灰绿先放着；尽快做剩余 ≤48 小时自动进入马上做。
- **桌面融合**：弱边框与阴影，闲置时淡化工具栏；背景和文字透明度分别调节，背景支持 100% 透明；鼠标穿透可通过快捷键或托盘解锁。
- **随手记录与小窗**：全局快捷键、当前任务和接下来两件、托盘与原生应用图标。
- **计划与截止独立**：本周拖动只改执行日期，截止日历单独管理截止时间；文件可直接拖入任务。
- **新增日常功能**：每天/工作日/每周/每月重复任务、子清单、30 分钟后再提醒、CSV 导出。
- **本地优先**：无需账号、离线运行、原子保存、撤销、回收站、JSON 恢复与最近七日备份。

## English

Rixu is a quiet, local-first desktop planner. Today, Week, urgency quadrants and Inbox share one task store. Plan your top three, drag tasks onto days, attach local files, capture thoughts with a global shortcut and keep a tiny always-on-top queue.

Version 1.0 adds desktop blend mode, independently adjustable background/text transparency, recoverable mouse-through locking, recurring tasks, checklists, 30-minute snooze and CSV export. Planning dates and deadlines remain independent. No account, ads, telemetry or cloud sync. The app UI is currently Simplified Chinese; documentation is available in Chinese and English.

## Signing and upgrade / 签名与升级

**Windows is unsigned. macOS is ad-hoc signed and not notarized.** These builds do not have a trusted developer certificate; first launch may trigger system checks. Bundle signature integrity was tested on Mac, which does not establish publisher trust. 本版尚未配置开发者签名证书，Windows 未签名，macOS 临时签名且未公证；首次启动可能需要系统审核。

Existing users retain data under the legacy `四格` app-data directory. Schema 1/2 upgrades to schema 3. Back up before downgrading, and restore a matching older backup if you do. File attachments store paths, not copies of file contents. Notifications require the app to remain running. Source is public; no open-source license has been granted at this time.
