# 日序 · Rixu 1.0.1 — 应用内双语 / In-app language switching

补齐应用内中文、英文切换。打开 **更多 → 设置与备份 → 语言 / Language**，选择简体中文或 English，即时生效，无需重启，并记住下次启动的选择。

翻译覆盖主导航、四档优先级、今天与本周、截止日历、任务编辑、子清单与重复选项、设置、快捷记录、托盘菜单、通知和应用错误提示。任务标题、备注、文件名和子清单内容保持原样；切换不会丢失未提交的编辑和快捷记录草稿。旧数据默认保留中文。

**English:** The app now supports both Simplified Chinese and English. Open **More → Settings and backup → 语言 / Language** to switch immediately. Your choice survives a full restart. Navigation, priorities, planning views, deadline calendar, editor, settings, quick capture, tray menus, reminders and app errors follow your choice. Your own task content and unsaved drafts remain unchanged.

## Validation / 验证

The four-platform workflow runs 38 unit cases (one symlink-only case is skipped on Windows), four native UI suites including dedicated language coverage, and packaged/installed app tests. Package tests switch to English through Settings, fully quit and restart the executable, then verify the saved language and task. See the attached verification summary and 20 machine-readable test reports for the exact successful commit and workflow.

Windows x64, Debian/Ubuntu x64, Linux archive, Apple Silicon Mac and Intel Mac downloads are attached, with SHA-256 checksums. Existing tasks and settings are preserved.

签名状态不变：Windows 未签名，macOS 临时签名且未公证。操作系统自带的对话框控件可能跟随系统语言。

Signing remains unchanged: Windows is unsigned; macOS is ad-hoc signed and not notarized. OS-native dialog controls may follow the system language.
