# 日序：把计划轻轻放在桌面上

日序服务于一个很小但经常出现的需要：不想打开复杂的项目管理工具，只想知道现在该做什么、这周怎么安排、哪些事情快到截止了。

主面板用四档颜色表达处理顺序：马上做、尽快做、按计划做、先放着。四象限是四档优先级，并不是“重要/不重要”的两轴矩阵。任务接近截止会变色，尽快做在剩余 48 小时内自动显示到马上做。

当你需要行动，切换到今天，把三件最重要的事放在最上方；当你需要安排，切到本周，用预计耗时看看哪一天排得太满。计划日期与截止时间分开，不会因为调整日程把真正的截止日期弄丢。

想到新事情时，按全局快捷键，输入、回车，然后继续手头工作。文件可以直接拖进任务。复杂一点的事情可以拆成子清单，经常做的事情可以设为重复任务。提醒可以稍后再来，不必改掉截止时间。

日序可以成为桌面上的安静一层：弱边框、独立的背景和文字透明度、闲置时淡化的工具栏、鼠标穿透锁定，以及只留下当前任务和下两件事的小窗。它保留解锁入口，让简洁不以“找不到按钮”为代价。

所有任务首先属于你的电脑。无需账号，离线运行，自动备份，可导出 JSON 与 CSV。v1.0 聚焦单人桌面计划，没有云同步和团队协作。

Windows、Linux 和两种 Mac 架构都有对应构建流程。具体下载、测试记录和代码签名状态以 [Release](https://github.com/asoming/rixu/releases/latest) 为准。

应用支持简体中文和英文。在「设置与备份 → 语言 / Language」即时切换，重启后保留选择，任务内容与未提交草稿保持原样。
