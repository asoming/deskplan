# 日序 · 桌面计划 PRD v1.4

应用版本：1.0.2 · 2026-09-13

## 产品定位

日序，让每天的安排有次序。以常驻桌面的简洁面板，把临时想法、今天行动、本周安排和截止紧急程度放在同一个本地 App 中。独立应用图标使用日历页、任务清单和勾选符号，强调计划与推进。

## 页面与核心流程

| 入口 | 内容 | 核心操作 |
| --- | --- | --- |
| 今天 | 顶部最多 3 件重要任务，下方其他待办 | 点星标加入重点；拖动排序或移出重点；填写预计耗时 |
| 本周 | 周一至周日七列，每天的任务、已估时总量、未估时数量 | 拖动安排日期；切换上下周；超容量标记偏满 |
| 四象限 | 马上做、尽快做、按计划做、先放着 | 拖任务分区；拖本地文件新建任务或关联已有任务 |
| 收集箱 | 未安排的临时任务 | 快速记下；安排今天或选择日期 |
| 小窗 | 当前任务和接下来两件 | 不置顶常驻、完成、展开；当前任务可由用户指定 |
| 截止日历 | 每日到期任务 | 点日期筛选；拖入修改截止日期 |

新任务可以先收集，也可以直接安排日期。计划日期代表打算哪天执行，截止时间代表最晚何时完成，两者分别保存。本周拖动不能改截止时间；截止日历拖动会保留原时间，仅修改日期。

今天包含计划日期在今天或之前的未完成任务；旧任务没有计划日期时，用截止日对应日期辅助呈现。未完成的过去计划保留原日期并显示「之前待办」，不会悄悄改期。每日重点由用户手选，最多三件，满额时第四件加入失败且不改变原数据。

## 紧急程度与颜色

| 分区 | 颜色 | 用途 |
| --- | --- | --- |
| 马上做 | 红 | 当前需要优先推进 |
| 尽快做 | 橙 | 近期推进；距截止 ≤48 小时自动显示在马上做 |
| 按计划做 | 蓝 | 已安排、按节奏执行 |
| 先放着 | 灰绿 | 暂缓处理或保留想法 |

这四个区表示四档处理优先级，并非重要性与紧急性的两轴矩阵。卡片截止提示独立变化：超过 7 天使用分区色，7 天内暖黄，48 小时内橙，24 小时内红，逾期红色并显示「已逾期」。文字状态与颜色同时表达，不只靠颜色识别。

自动升级按实际剩余小时计算，不按日历天四舍五入。仅尽快做自动进入马上做；手动设为马上做不会因延后截止自动降级。尽快做改为超过 48 小时后回到原区。启动、分钟刷新、休眠恢复后重新计算。

## 桌面交互

1. 全局快捷键 Ctrl / ⌘ + Shift + 空格唤起轻量输入框。输入回车保存到收集箱并隐藏；Esc 或失焦收起，未提交文本暂存于当前窗口会话。输入法选字不误提交。快捷键冲突可切换 Alt + Shift + 空格，或从托盘打开。
2. 小窗默认 390 × 320，不置顶，只显示当前和接下来两件任务。没有指定当前任务时，优先展示今日重点、其他今日任务，再按紧急程度补齐。完成后补位。
3. 背景透明度、文字透明度分别为 0–100%。100% 背景透明时面板、分区和卡片底色均透明；任务文字独立控制。工具栏、弹窗和设置保留可见，可用托盘恢复默认可见状态。
4. 关闭主窗可保留后台运行；退出菜单彻底退出。托盘提供显示、随手记、恢复可见、固定位置和退出。

## 任务数据

任务字段：重复规则、重复锚点、上一轮任务标识、子清单、稍后提醒时间，以及标识、标题、备注、用户分区、计划日期、截止时刻、截止版本、预计分钟数、排序值、重点日期、当前任务标识、是否在收集箱、状态、附件路径、提醒偏好、创建与修改时间。

状态包括待办、已完成、已取消、回收站。完成/取消后可以恢复待办；只有回收站可永久删除任务记录，任何任务操作都不删除磁盘原文件。附件失效可重新定位。预计耗时为整数 0–1440 分钟，0 为未估时。

## 提醒与未完成任务

系统通知由用户开启；首次默认只在截止时提醒，提前 24 小时可选。应用完全退出时不提醒。使用截止版本与提醒类型去重，正常运行或休眠恢复时只发一次。

到期任务点击「处理到期」，或点击系统提醒后，提供：延期至用户指定的未来时间、保留待办、取消任务、30 分钟后再提醒。稍后提醒不修改截止日期，使用单独的时间与去重记录；选择保留或重新安排截止会清除待发的稍后提醒。保留不改原截止时间、不重复轰炸；延期增加截止版本，按新时间提醒；取消保留记录并可恢复。多个错过提醒合并通知，其他到期任务仍可从四象限逐项处理。

## 本地优先与可靠性

无需账号，无网络依赖。任务保存采用原子写入，保存失败不报告成功。支持最近操作撤销、JSON 备份恢复、CSV 可读导出、每日最近 7 份备份和异常数据恢复。导出包含任务与附件路径，不包含原文件。恢复前另存当前数据。旧版 schema 1 / 2 升级为 schema 3，保留原日期、路径和提醒记录。

## 桌面融合与重复计划（1.0 新增）

- 工具栏「融入」切换桌面融合：减弱边框与阴影，降低背景块存在感；闲置时淡化工具栏，鼠标移入或按 Tab 导航时恢复。背景透明度保持独立可调。
- 「更多 → 锁定并穿透鼠标」使鼠标操作落到背后窗口。Ctrl / ⌘ + Shift + L 或托盘可以解锁；启动时默认解锁。仅在至少一个恢复入口可用时允许锁定。
- 应用仍为独立桌面窗口，不嵌入壁纸、不修改 Explorer；定位与穿透效果受桌面环境支持限制。
- 重复任务支持每天、工作日、每周、每月，需先安排日期或截止时间。完成后生成下一次；晚完成时跳过过去日期，不批量创建逾期副本。每月 31 日遇短月取月末，之后恢复 31 日锚点。
- 下一轮保留标题、备注与附件关联，重置子清单。完成后撤销会移除自动生成的下一轮；重复完成同一轮不重复生成。
- 每个任务最多 30 项子清单，卡片显示完成进度。步骤只在编辑保存后持久化。
- CSV 导出保存可读任务内容、日期和状态；为表格公式前缀添加防护。JSON 仍为完整恢复格式。

## 原生发行与质量门槛

Git 管理源代码，公开仓库为 [asoming/rixu](https://github.com/asoming/rixu)，提供中文、英文 README 和产品介绍。Windows x64 使用 NSIS 安装程序；Linux x64 提供 Debian 包与 tar.gz；Apple Silicon / Intel Mac 分别提供 DMG 和 ZIP。使用日历、计划清单与勾选元素作为 App 图标，提供桌面入口与系统托盘。

只有同一提交的四个平台作业均通过，才将对应产物发布为正式版。检查包括任务与存储单元测试、真实 Electron 界面、打包后 ASAR 加载、持久化及退出、Windows 实际安装、macOS DMG 挂载和签名完整性、Debian 解包后的桌面入口与启动。发行页提供 SHA-256 校验值和验证记录。

本版未配置商业签名证书：Windows 未做 Authenticode 签名；macOS 为 ad-hoc 签名且未公证。签名信任、每种 Linux 桌面环境和系统通知服务的表现不属于自动化测试能够完全证明的范围。

调研依据和取舍见[用户痛点调研](https://github.com/asoming/rixu/blob/main/docs/RESEARCH.zh-CN.md)。来源为公开用户讨论与 issue，属于定性样本，不将历史反馈等同于竞品当前缺陷。

## 本版验收

- 今天可排序，重点最多三件，完成与撤销持久化。
- 七天看板包含预计耗时、未知耗时计数和超容量状态，拖动不影响截止版本。
- 收集箱与四象限不重复展示未安排任务，全局输入保存后收起。
- 小窗为原生非置顶窗口，显示当前与下两件；展开恢复正常尺寸。
- 四个分区颜色不同，48 小时自动升级边界准确。
- 背景可完全透明，文字透明度互不影响，仍可恢复设置。
- 到期后延期、保留、取消含义不同且可验证。
- 旧数据升级、附件路径、备份和撤销无丢失。
- 重复任务跨月、晚完成与撤销规则准确，子清单新一轮重置。
- 稍后提醒不修改截止时间，CSV 可读且完整 JSON 可恢复。
- 鼠标穿透可恢复，完全透明时仍保留操作入口。
- 四个平台从同一提交构建，实际发行包验证通过后才发布。

## 暂不纳入

云同步、账号系统、团队协作、自然语言日期识别、番茄钟、系统日历双向同步。这些可作为后续版本候选，不增加当前主界面的负担。

## 1.0.2 应用内双语

设置顶部增加「语言 / Language」选项，支持简体中文与 English，即时生效并持久保存。翻译覆盖导航、四档优先级、日历、时间提示、编辑器、设置、快捷记录、托盘、通知和应用错误提示。任务标题、备注、子清单与文件名由用户维护，不翻译、不重写；未提交草稿在切换时保留。原生操作系统控件可能跟随系统语言。旧数据默认保留中文，可随时切换。

## 右上角停靠与固定位置（1.0.2）

默认靠屏幕可用区域右上角停靠，距边缘 24 像素；新安装默认 760 × 540。固定位置默认开启，任务编辑、勾选和文件拖放照常工作。左侧图钉可解锁，拖动顶部空白处后再固定；斜向箭头可回到右上角。设置中的「右侧留白」可额外预留 0–480 像素。切换小窗后继续贴靠右上角，手动位置在展开时恢复。显示器移除或分辨率变化时保持在可用区域内。

主面板、小窗和随手记均不设为置顶，其他应用可以正常盖住日序。旧备份中的置顶选项会被关闭。功能入口集中到左侧小图标栏，悬停显示当前语言的名称；面板内不再显示品牌图标。应用启动器图标继续用于找到和打开软件。

固定位置与鼠标穿透是不同功能：固定仅禁止移动窗口，穿透会把点击交给后方桌面。程序不会移动桌面文件，也不能跨系统自动识别并避开每一个桌面图标；右侧留白、手动位置、穿透和收起可用于让出文件区域。测试使用隔离显示或 CI，不自动重启工作中的用户实例。
