# 日序 0.2.0

一个有独立图标、离线可用的桌面计划软件。无需注册。

- **今天**：手选最重要的 3 件事，下面是其他待办；拖动排序，标注预计分钟数。过去安排但未完成的任务也会出现在今天，并标记「之前待办」。
- **本周**：周一到周日安排任务，拖动只改变计划日期，不改变截止时间。每日默认容量 360 分钟，可在设置中调整；超出时标记「偏满」，未估时任务单独计数。
- **四象限**：红色马上做、橙色尽快做、蓝色按计划做、灰绿先放着。拖入真实文件建立关联；点击任务详情中的文件按钮打开原文件。尽快做的任务剩余不超过 48 小时自动显示在马上做，改期后重新判断。
- **收集箱**：先记后安排；Ctrl / ⌘ + Shift + 空格弹出输入框，回车保存并收起，Esc 关闭。输入法选字期间回车不提交。若快捷键被占用，可在设置中换为 Alt + Shift + 空格，或通过托盘「随手记」打开。
- **置顶小窗**：点击「小窗」显示当前任务与接下来两件；完成后自动补位。点击任务的「开始」指定当前任务，展开后回到完整计划。
- **截止日历**：查看每天到期任务；拖到日历日期会修改截止日期，保留原时刻。与本周的计划日期分开。
- **温和提醒**：在设置中开启系统通知。新用户默认只在截止时提醒；提前 24 小时可选。任务到期后可延期、保留待办或取消，取消后可在「更多 → 已取消」恢复。不会自动延期或取消。退出 App 后不再提醒，休眠恢复时检查错过的提醒。
- **透明度**：背景和文字分别为 0–100%；背景 100% 为完全透明。工具栏、设置面板保留可见，便于恢复。托盘菜单可「恢复可见」。
- **本地数据**：自动保存、撤销、回收站、JSON 导入导出、每日最近 7 份滚动备份。附件只保存路径，备份不包含原文件。

## 安装与运行

当前提供 Linux x64 桌面应用和 Debian 安装包。已在当前 Linux 桌面验证真实窗口、文件拖入、系统快捷键注册、置顶与数据持久化。Windows/macOS 尚未构建或验证。

便携包解压后运行 `启动日序.sh`，或直接运行 `rixu`。日常使用无需 Node.js。

开发需要 Node.js 22.12+：`npm install`、`npm start`。测试：`npm test`；有桌面会话时运行 `npm run test:desktop` 与 `npm run test:planner`。禁止把测试数据目录设置为真实用户数据目录。

升级沿用旧版的用户数据目录（Linux 为 `~/.config/四格`），自动读取旧格式并补全新增字段。任务、附件路径和提醒记录保留。0.2.0 保存后的 schema 2 备份不能交给 0.1.x 直接使用；请在回退时恢复升级前备份。

## 边界

这是本地单人计划软件。暂不包含云同步、团队协作、系统日历双向同步或重复任务。透明窗口的最终外观、托盘和全局快捷键取决于桌面环境；快捷键注册状态会显示在设置中。本周容量是预计耗时总和，不等于实际连续空闲时段。
