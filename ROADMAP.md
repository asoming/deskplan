# Direction / 后续方向

These are discussion areas, not promised features or delivery dates. Propose a concrete use case in [Issues](https://github.com/asoming/deskplan/issues/new?template=feature_request.yml).

以下是待讨论的方向，不是功能承诺或交付时间表。

- **Desktop reliability / 桌面兼容性:** collect reproducible cases across Linux desktop environments, multiple monitors and display scaling.
- **Accessibility / 可访问性:** improve keyboard navigation, focus visibility and readable text on varied wallpapers.
- **Installation / 安装体验:** evaluate developer signing and macOS notarization when the required certificates are available.
- **Planning clarity / 计划清晰度:** refine checklists, overloaded-day signals and deadline visibility based on real use.
- **Documentation / 文档:** improve screenshots, bilingual guidance and troubleshooting based on recurring questions.

The core stays local-first and quiet. Accounts, cloud synchronization and team workflows are not currently part of the product scope.

核心仍是本地优先、安静常驻；账号、云同步和团队协作当前不在产品范围内。
